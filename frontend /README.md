# Лабораторна робота №5  
## Захист вебзастосунку від типових вразливостей

### Тема
Реалізація захисту вебзастосунку від типових вразливостей:
- SQL Injection
- XSS
- IDOR
- Security Misconfiguration

---

## Мета роботи

Ознайомитися з основними вразливостями вебзастосунків та реалізувати механізми захисту в існуючому застосунку системи пропусків у комп’ютерний клас.

---

## Опис застосунку

Було використано вебзастосунок «Система пропусків у комп’ютерний клас», який складається з:

### Backend
- Node.js
- Express
- TypeScript
- SQLite

### Frontend
- HTML
- CSS
- JavaScript (Fetch API)

Функціональність:
- створення пропусків;
- перегляд пропусків;
- редагування;
- видалення;
- фільтрація та сортування.
